GoblinReactor

A local development environment on your phone. No rooting or remote server required.

Use apt packages, open multiple terminals, run editors and development tools, and keep your own services running in the background. It uses packages from Debian. The preview includes the native kitty terminal and the stable 7.2.9-goblin kernel.

Download Android APK · @@SIZE@@ MiB

For ARM64 Android devices. Android 12 or newer recommended. This is a sideload preview, not a Google Play release. Android 10–11 are experimental.

Install the preview

  1. Download the APK on your phone and open it.
  2. If Android asks, allow installation from the browser or file manager you used. You can turn that permission off again after installing. Keep Android's security protections enabled.
  3. Open GoblinReactor. First launch prepares the environment locally and can take several minutes.
  4. Your shell account is goblin. Try sudo apt update, then install the tools you need.

Installation does not require Android root or developer mode. A 64-bit processor running a 32-bit Android installation is not compatible.

Before you try it

This is early software. Keep a backup of important work using Back up environment… in the app menu. Uninstalling the app or clearing Android storage deletes its local installation. Running services and the optional keep-awake setting use battery; Shut down environment… stops the guest.

The public app ID is dev.goblinreactor.sentry. Updates to this preview will use the same identity and signing key.

Help test it

Try setup, typing and scrolling, package installation, editors, background work, and backup. Reply to the LinkedIn preview post with your phone model, Android version, and what worked or failed. Save diagnostics… creates a local report you can review before sharing. Avoid posting personal files or terminal secrets.
