# GoblinReactor 0.3.3

October 5, 2026 · version code 30003 · ARM64 Android

- The app is now named GoblinReactor. Launcher labels, help, the running-session
  notification and exported backup filenames use the updated branding.
- Open-source notices now include project licensing, Debian seed/deployment and
  boot-tool notices, Android runtime notices and additional Python dependencies.
- The release includes matching upstream sources, local modifications, build
  instructions, a source inventory, APK/App Bundle artifacts and checksums.
- The application ID and signing identity are unchanged. Install over the
  previous release to retain the local installation; do not uninstall first.

The kernel, terminal engine and guest runtime are unchanged from the preceding
0.3.2 build. This release does not add device support or establish Google Play
eligibility. Android 12+ with a 64-bit ARM64 Android installation is the support
target; Android 10–11 remain experimental. Validation scope is recorded in
VALIDATION.md. Broader device and long-duration testing remains outstanding.
