# GoblinReactor 0.3.7 preview

October 5, 2026 · version code 30007 · ARM64 Android

- Menus, notifications, status messages and recovery prompts use “environment”
  instead of upstream project names. Help and installation instructions match.
- About, documentation and the download page acknowledge upstream trademarks
  and clarify that the project is independent of the **Debian** Project.
- Updates retain the `dev.goblinreactor.sentry` app ID, GoblinReactor signing key,
  installed files, packages and preferences.
- The stable 7.2.9-goblin kernel, packaged guest and supplied Goblin icon are unchanged.

This is an early sideload preview for Android 12+ on ARM64 devices, not a
Google Play release. Android 10–11 remain experimental. See VALIDATION.md for
what was tested. Back up work before relying on preview software.
