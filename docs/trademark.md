# GoblinReactor naming and trademark usage

Product name and public display: **GoblinReactor**.
Description: **A terminal and local development environment for Android.**

Use this name in the launcher, app title, notifications, store listings, release
filenames and documentation. Use the supplied Goblin character artwork as the app icon. Do not add Linux®
to the product name, logo or brand identifier.

Linux references describe the kernel and operating environment provided by the
app. For example: “GoblinReactor runs a Linux® kernel with Debian ARM64 packages.”
Keep these descriptions separate from the product name and retain attribution.

The [Linux Foundation's mark policy](https://www.linuxfoundation.org/legal/the-linux-mark)
distinguishes use in a brand identifier, which requires a sublicense, from
non-trademark fair use. This naming approach removes Linux from our brand rather
than relying on a product-name sublicense. It does not claim endorsement,
certification or a granted sublicense. The previous naming plan is superseded;
no response to the trademark inquiry has been received as of October 4, 2026.

The Android application ID and Java/JNI namespaces use
`dev.goblinreactor.sentry`. Preview builds use a GoblinReactor signing identity.
This identity is established before public distribution. Historical internal
test evidence and archived artifacts retain their original identifiers; they
are not the public preview. Existing local test copies are separate Android
applications and are not silently removed or migrated.
